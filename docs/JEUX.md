# Les 15 jeux (clé = identifiant dans `GAMES`)

| Clé | Nom | Notes |
|---|---|---|
| culture | Culture générale | QCM, 20 s |
| estimation | Estimation | nombre à deviner, points 30/20/10/0 |
| bluff | Le Bluff | fausses réponses à démasquer, vote |
| ordre | Dans l'ordre ! | classer des éléments (glisser) |
| drapeaux | Drapeaux | `flags/` |
| pyramide | Pyramide | oral, 2 joueurs (donneur + partenaire), jamais en finale |
| croquis | Croquis | dessin façon Pictionary, jamais en finale ; mot accepté avec fautes mais pas un autre vrai mot du dictionnaire |
| imposteur | L'Imposteur | min. 3 joueurs, vote |
| rebus | Rébus emoji | emojis Unicode 9 max (vieilles télés) |
| petitbac | Petit Bac | unique 6 pts / partagé 3 pts, vérification collective |
| reflexe | Réflexe | chrono fixe 15 s |
| memoire | Mémoire flash | grille d'emojis |
| geo | Géo-Devine | cliquer sur la carte, points selon la distance |
| chrono | Pile-poil | chrono fixe |
| bombe | La Bombe | mots à contenir une syllabe, chrono fixe |

## Règles transverses
- `duo`/`nofinale` : exclus de la finale (`fixFinale`). Finale = 3 dernières manches ×2.
- Réponses écrites : tolérance aux fautes (`normText`, `phon`, `lev`, `matchGuess`).
- Pas de « Le saviez-vous » après les réponses.
- Public : jeunes adultes ; questions Bluff/Culture G fun ; banque toute faite (pas de questions écrites par la famille).
